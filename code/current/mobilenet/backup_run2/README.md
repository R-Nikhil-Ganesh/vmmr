# backup_run2

35-make (Run 2) diagnostics that were left in the Run 3 output folders after the 1,235-class models overwrote the weights.
They describe the old 35-class models, not the current ones: confusion matrices, classification reports, calibration and t-SNE plots.
`training_run1.log` is the leftover training log (Run 1, 35 classes). The Run 2 ONNX weights are only in git history (commit af37374).
Run 3 diagnostics are regenerated by the analysis step of `bash_scripts/run_all_pipeline.sh` or `bash_scripts/run_diagnostics.sh`.
